# FarmShield
```
farmshield/
  backend/    Node + Express + MongoDB  (your original project, unchanged)
  frontend/   React app (new UI, same features and same API calls)
```
## Run
Terminal 1 (backend):  `cd backend && npm install && npm start`   -> http://localhost:3000
Terminal 2 (frontend): `cd frontend && npm install && npm run dev` -> http://localhost:5173

Login boxes are empty - enter your own registered email/password.
Admin login page: http://localhost:5173/#/admin-login
